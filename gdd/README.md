# Game design doc

This folder is the game as Daka wants it. It replaces the older `design/` notes, which were stand-ins.

Every rule carries one of three marks:

| Mark | Meaning |
| --- | --- |
| **Decided** | Daka said it. Build it this way. |
| **Proposed** | A suggestion that fills a gap. Not final until Daka confirms or changes it. |
| **Open** | Nobody has decided yet. Do not build it until it is answered. |

The doc is written from interviews with Daka, one round at a time. Edit any line directly; a changed line
becomes **Decided**.
